# Task Management REST API

A backend learning project built with Node.js core HTTP module
to understand REST API and backend fundamentals.

## Tech Stack

- Node.js
- JavaScript
- Node.js HTTP module
- Postman

## Current Features

- HTTP server
- Request and response handling
- REST API
- Route parameters
- Query parameters
- CRUD operations
- JSON handling
- Status codes
- Headers
- Input validation
- Error handling

## API Endpoints

| Method | Endpoint   | Description             |
| ------ | ---------- | ----------------------- |
| GET    | /tasks     | Get all tasks           |
| GET    | /tasks/:id | Get one task            |
| POST   | /tasks     | Create a task           |
| PUT    | /tasks/:id | Update a task           |
| PATCH  | /tasks/:id | Partially update a task |
| DELETE | /tasks/:id | Delete a task           |

## Database

Currently uses an in-memory JavaScript array as a temporary database.
